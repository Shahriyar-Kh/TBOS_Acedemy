# Phase 15: Off-Page SEO & Long-Term Organic Growth Plan

**Academy**: TechBuilt Open School International Online Academy  
**Production Domain**: `https://techbuiltos.online`  
**Growth Philosophy**: 100% White-Hat, Sustainable, People-First Digital Reputation.

> [!CAUTION]
> TechBuilt Open School strictly prohibits black-hat link schemes, automated spam backlinks, private blog networks (PBNs), purchased Fiverr link packages, fake Google Business Profile locations, and fabricated student reviews. Sustainable domain authority is built through genuine educational value, verified alumni satisfaction, and legitimate institutional relationships.

---

## 1. Organic Growth Pillars

### Pillar 1: High-Utility Educational Content (Linkable Assets)

Search engines and community members naturally link to resources that solve specific, difficult questions clearly.

- **Publish Original Roadmaps**: The 6 evergreen guides created in Phase 15 (`/blog/python-learning-roadmap-beginners`, `/blog/data-analyst-roadmap`, etc.) serve as definitive primary reference materials.
- **Code Repositories on GitHub**: Publish open-source curriculum capstone templates and starter code repositories under the official GitHub profile (`Shahriyar-Kh/TBOS_Acedemy`), linking back to relevant course roadmaps.
- **Interactive Checklists & Cheat Sheets**: Free PDF/markdown downloads for SQL cheat sheets, Python syntax quick references, and study schedules.

### Pillar 2: Authoritative Digital Profiles & Branded Citations

Claim and maintain official brand profiles across credible platforms with consistent Name, Address (Online), Phone (NAP), and Website data:

1. **GitHub Organization**: Maintain active code samples and student project templates.
2. **Social Channels**:
   - Facebook (`https://www.facebook.com/profile.php?id=61589216685624`)
   - Instagram (`https://www.instagram.com/techbuiltopenschool/`)
   - TikTok (`https://www.tiktok.com/@techbuiltopenschool`)
   - LinkedIn: Establish an official TechBuilt Open School Company page.
3. **Legitimate Educational Directories**: Submit academy information to curated Pakistani and international educational directories (e.g., PakStudy, IlmKiDunya educational portal, reputable online tutoring directories) without paying for link networks.

### Pillar 3: Multi-Platform Content Repurposing

Maximize the reach of each core educational article:

- **LinkedIn Articles & Carousels**: Convert the 100 Days Python Plan and Data Analyst Roadmap into PDF carousel slides highlighting core skills (SQL + Pandas + Power BI).
- **Instagram & Facebook Visual Posts**: Infographics summarizing "5 Red Flags When Choosing an Online Tutor" and "Coding Milestones for Kids Aged 10–16".
- **Short-Form Video (TikTok & Reels)**: 60-second video tips by instructors explaining quick debugging techniques, Python tricks, or student advice.

### Pillar 4: Earning Genuine Backlinks (Digital PR & Mentorship)

- **Guest Technical Articles**: Contribute educational guest articles to respected developer publications (Dev.to, Hashnode, Medium) explaining teaching methodologies and real project breakdowns, with natural references to the TBOS curriculum.
- **University & Student Community Collaboration**: Partner with computer science student societies and youth STEM clubs in Pakistan for live online coding workshops and free introductory webinars.

## 2. Prioritized Execution Timeline

### Phase A: First 7 Days (Immediate Post-Launch Baseline)

1. **Complete GSC Verification**: Follow `docs/phase15-google-search-console-runbook.md` to verify domain ownership via DNS TXT.
2. **Sitemap Indexing**: Submit `https://techbuiltos.online/sitemap.xml` and request manual indexing for the top 12 priority URLs.
3. **Social Profile Audit**: Ensure all bio links on Facebook, Instagram, TikTok, and GitHub point to the canonical HTTPS root (`https://techbuiltos.online`).
4. **Setup Weekly Automated Monitoring**: Activate the `.github/workflows/seo-health.yml` workflow to monitor route uptime and metadata health.

### Phase B: First 30 Days (Indexing Reinforcement & Distribution)

1. **Review GSC Page Indexing**: Verify that all 90 public pages transition from "Discovered" to "Indexed".
2. **Distribute 6 Evergreen Guides**:
   - Share one resource per week across Facebook, Instagram, and LinkedIn.
   - Cross-post adapted summaries on developer communities (Dev.to, Reddit r/learnprogramming where self-promotion rules permit educational resource sharing).
3. **Create LinkedIn Company Page**: Establish the official TechBuilt Open School page, link to the website, and invite mentors and alumni to list their affiliation.
4. **Monitor Search Queries**: Identify early search queries in GSC and assess whether user intent matches landing page expectations.

### Phase C: First 90 Days (Authority Building & Expansion)

1. **Curriculum Expansion**: Review search trends in GSC. If high impression volume exists for terms like "FastAPI tutorial" or "Power BI DAX formulas", draft two additional deep-dive guides for `/blog`.
2. **Student Project Showcases**: Publish student project writeups and capstone demonstrations on the academy blog and social channels (with explicit student/parent consent).
3. **Educational Directory Submissions**: Complete 5–10 manual submissions to legitimate, non-spam education directories.
4. **Quarterly Technical SEO Audit**: Run `npm run seo:audit`, `npm run seo:links`, and `npm run seo:metadata` to catch any dead links, redirect chains, or content regressions.
