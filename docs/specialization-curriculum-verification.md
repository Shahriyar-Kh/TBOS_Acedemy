# Specialization Curriculum Verification

Last reviewed: 2026-10-15

This audit keeps every specialization tied to teachable single-course roadmaps and uses primary product documentation for custom modules. It is a curriculum alignment record, not an accreditation claim.

## Delivery and pricing

- One-to-one: the existing monthly price is preserved (PKR 20,000 for premium tracks; PKR 15,000 for standard tracks).
- Live group batch: 60% off the corresponding one-to-one price (PKR 8,000 or PKR 6,000 per month).
- Group size: 5–10 students.
- Both formats: four live online classes per week, recordings, guided practice, course projects, and a final integrated capstone.

## Quality rules

- Every specialization contains complete courses rather than marketing-only module labels.
- Linked courses reuse the approved single-course chapter roadmap.
- Every included course has a practical project.
- Every specialization ends in an integrated capstone.
- Custom modules cover current official concepts such as accessibility, testing, security, model evaluation, deployment, performance, and responsible use.
- Pages must not promise employment, income, certification, or guaranteed outcomes.
